# 为什么好的排版，是公众号的「隐形编辑」

你有没有过这样的体验——打开一篇公众号文章，看了两行就划走了。不是内容不好，是眼睛在说「不」。

密密麻麻的字、没有呼吸的间距、颜色刺眼得让人想关掉页面。排版从来不是「锦上添花」，它是内容的容器。容器破了，水就洒了。

## 排版的第一性原理：降低阅读阻力

公众号文章是在手机上看。手机屏幕窄、阅读场景碎片化——地铁上、吃饭前、睡前。这意味着排版的第一目标不是「好看」，是「好读」。

好读 = 低阻力。低阻力 = 读者愿意看完。

什么是阻力？一行 50 个字挤在一起（阻力）。字号 12px 比蚂蚁还小（阻力）。段落之间没有间距，灰蒙蒙一片（阻力）。

什么是顺滑？14px 正文，1.85 倍行高，0.3px 字间距。段落之间有呼吸。重要的句子被单独拎出来，加粗，加颜色。

**排版的本质不是装饰，是降低认知负荷。**

## 卡片：让信息「可视化」

人脑不是按段落理解的，是按「块」理解的。这就是为什么大段文字会被跳过，但一张卡片、一个列表、一段粗体引用会被阅读。

把信息装进卡片里：

- 核心观点 → 做成金句卡，居中展示
- 数据 → 做成数据卡，放大数字
- 步骤 → 做成步骤流，编号 + 说明
- 引用 → 做成引用块，左边框 + 强调色

每一张卡片都是给读者的一个「视觉锚点」。锚点越多，读完率越高。

## 主题：风格即态度

排版不只是功能问题，也是气质问题。一篇科技深度文用粉嫩渐变排版，读者会觉得奇怪。一篇美食探店用极简黑白，也显得冷冰冰。

所以排版要先定调——这个内容是什么性格？

- 科技深度 → 暗色、荧光强调、终端感（深海主题）
- 生活治愈 → 暖色调、圆润卡片、柔和对比（暖橙/苔原）
- 商业分析 → 干净、克制、数据清晰（素白/Stripe）
- 文艺情感 → 紫调、渐变、浪漫（紫调主题）

**主题不是皮肤，是内容的语气。**

## 写在最后

排版这件事，说到底是尊重读者。

你用 14px 而不是 12px，是因为你知道对方可能在地铁上看。你留了 20px 的卡片间距，是因为你知道连续三段密文字会让人窒息。

好的排版不会被注意到——因为它没有制造任何障碍。坏排版才会让人皱眉。

而你的内容，值得被好好读完。
