# gzh-AI-Design · 公众号 AI 排版引擎

> 输入 Markdown → AI 自动设计主题 → 生成公众号兼容 HTML → 手机框预览 → 一键复制到公众号 / API 推送到草稿箱

纯知识驱动，不依赖任何后端服务。AI 读设计规范 → 理解你的文章 → 为每篇文章原创独一无二的排版。

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 它能做什么

你写好 Markdown 文章，对 AI 说一句「帮我排版」——

1. AI 分析你的文章类型和情绪（教程？观点？测评？温暖？理性？）
2. 从 6 套设计语言中选最契合的（或你指定，或 AI 完全原创）
3. 按微信公众号 HTML 规范生成排版（100% 内联样式，标签白名单，粘贴后样式不丢失）
4. 自动校验合规（`validate_gzh_html.py`，0 ERROR 才交付）
5. 生成手机框预览页 — 双击打开就能看到效果
6. 一键复制到公众号后台，或直接 API 推送到草稿箱

排版后不满意？说一句「标题颜色改深一点」— AI 直接修改输出文件，不用重来。

## 6 套设计语言

每套都是一组设计变量 + 设计原则 + 组件模式 — AI 理解气质后为你的文章进行原创演绎。

| # | 名称 | 气质 | 最适合 |
|---|------|------|--------|
| 1 | 极简蓝 | 克制 · 理性 · 呼吸感 | 技术教程、工具测评、知识整理 |
| 2 | 暖纸墨 | 温度 · 杂志感 · 细线分隔 | 观点分析、深度文章、人文思考 |
| 3 | 暗夜青 | 科技 · 终端美学 · 霓虹克制 | 开发技术、数据报告、产品深潜 |
| 4 | 森语绿 | 自然 · 侘寂 · 大留白 | 随笔、生活方式、冥想反思 |
| 5 | 绯红编 | 编辑风骨 · 红白张力 · 结构感 | 深度评测、案例复盘、行业分析 |
| 6 | 墨金雅 | 墨色 · 金饰 · 经典比例 | 人物访谈、品牌叙事、高端内容 |

**三种排版模式：**

| 模式 | 说明 |
|------|------|
| **A. 预设主题** | AI 根据文章推荐最契合的主题，你一键确认 |
| **B. 自己描述** | 你说想要什么感觉（如「浅米色底，深咖字，像读纸书」），AI 执行 |
| **C. AI 全原创** | 不套任何预设，AI 根据文章内容从零设计整套视觉方案 |

## 公众号兼容性保障

所有规则基于**真实公众号文章源码逆向分析**，不是猜的。

| 保障 | 机制 |
|------|------|
| 标签白名单 | 只用 `<section>/<p>/<span>/<strong>/<em>/<img>/<br>` 7 个标签 |
| 样式保留 | 所有中文文字用 `<span leaf="">` 包裹 — 粘贴到公众号编辑器后样式不丢失 |
| 自动校验 | 生成后跑 `validate_gzh_html.py`，检查禁用标签/属性/CSS，ERROR 清零才交付 |
| 100% 内联 | 无 `<style>` 标签、无 class、无外部 CSS |

## 安装与使用

### 方式一：一句话安装（推荐）

对 AI 说：

```
帮我安装这个 skill：https://github.com/Patrick-mufeng/gzh-AI-Design-skill
```

AI 会自动拉取项目、安装到 skills 目录、完成配置。之后直接说「帮我排版」即可使用。

### 方式二：手动下载安装

1. 下载项目 ZIP 并解压
2. 将 `gzh-AI-Design-skill/` 文件夹放入 AI 工具的 skills 目录
3. 对 AI 说「帮我安装刚下载的 gzh-AI-Design-skill」
4. 安装完成后说「帮我排版 + 文章内容」

### 方式三：纯手动

用 Markdown 写好文章，参考 `references/` 下的规范自行编写 HTML。

## 推送功能设置

在项目根目录创建 `.env` 文件（AI 会在首次推送时引导你）：

```
WECHAT_APPID=wx1234567890
WECHAT_APPSECRET=your-32-char-secret
WECHAT_AUTHOR=你的作者名
```

**获取方式：**

1. 登录 [公众号后台](https://mp.weixin.qq.com) → 设置与开发 → 基本配置
2. 复制「开发者ID(AppID)」
3. 生成并复制「开发者密码(AppSecret)」
4. **IP 白名单**：同一页面添加你的公网 IP（AI 推送时会帮你查好）
5. 填到 `.env`，说「推送」即可

**未配置不影响排版使用** — 推送时自动降级为手动复制粘贴。

## 排版工作流详情

```
Phase 0: 读取文章 → 分析类型、情绪、结构特征
   ↓
Phase 1: 主题选择
   ├─ A: 预设主题（AI推荐最佳匹配）
   ├─ B: 用户描述风格
   └─ C: AI 全原创设计
   ↓
Phase 2: 前置阅读
   → 依次读取 spec-01~04 四个规范文件
   → AI 自检确认所有规则已过目
   ↓
Phase 3: 原创设计 → 生成 HTML
   → 读主题设计语言文件 + common-components
   → 分析文章结构，识别设计机会
   → 逐组件原创设计（非模板填充）
   → 全程遵守公众号兼容性铁律
   ↓
Phase 4: 生成预览 + 校验 + 交付
   → 生成 output.html
   → 生成 output-preview.html（注入HTML）
   → 跑 validate_gzh_html.py → 0 ERROR
   → 自动弹出浏览器预览
   → 用户可一键复制或进入推送
```

## 技术细节

| 项目 | 说明 |
|------|------|
| 依赖 | **零外部依赖** — 校验/推送脚本仅用 Python 标准库；预览页单文件 HTML |
| 协议 | `file://` 协议兼容，无需 HTTP 服务器 |
| 复制 | ClipboardItem API + execCommand 降级，白色背景自动包裹 |
| 排版兼容 | `<span leaf="">` 强制包裹保证粘贴后样式不丢失 |
| 样式语言 | 仅 `#hex` / `rgb()` / `rgba()`，禁 `hsl()` `oklch()` `var()` `calc()` |
| Flex 主力 | flex 是唯一稳定布局，grid 仅限 SVG 绝对定位叠加 |
| 字号基准 | 正文 14px / 行高 1.85 / 字间距 0.3px |

## 常见问题

**Q: 排版后粘贴到公众号，样式丢了？**
A: 这是公众号编辑器会剥离非白名单标签。本 skill 生成的是 100% 内联样式 + 7 个白名单标签 + `<span leaf="">` 包裹，首次粘贴前还会运行校验脚本确保合规。

**Q: 推送功能需要什么权限？**
A: 需要一个已认证的微信公众号（个人订阅号即可），在后台获取 AppID 和 AppSecret。只推送到草稿箱，不自动群发。

**Q: 图案、分割线、装饰元素会被过滤吗？**
A: 不会。所有装饰通过 flex 布局 + border + background + emoji 实现，不依赖 `<svg>` 或不安全 CSS。

**Q: 为什么不用 `<div>` 和 `<h1>` 标签？**
A: 微信公众号编辑器会剥离 `<div>` 并改写 `<h1>` ~ `<h6>`。本 skill 全部用 `<section>` + font-size 模拟标题层级。
