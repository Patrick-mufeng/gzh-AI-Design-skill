# WeMD · 公众号 AI 排版引擎

> 输入 Markdown → AI 自动排版 → 生成公众号兼容 HTML → 手机框预览 → 一键复制到公众号

**纯知识驱动，不依赖任何后端服务。一个文件夹，三个文件，换任何 AI 产品都能用。**

## 特性

- **📝 Markdown → 公众号 HTML** — AI 自动将你的文章转为微信兼容的排版
- **🎨 15 套主题色板** — 6 套进阶设计 + 9 套基础预设，也可 AI 自创主题
- **📱 手机框预览** — 双击 .html 即可在模拟手机中预览排版效果
- **🌙 暗黑模式** — 一键切换模拟微信暗黑模式
- **📋 一键复制到公众号** — 点击即复制富文本，公众号后台 Ctrl+V 粘贴
- **✏️ 修改排版** — 预览页点击修改，自动跳转编辑器，内容不丢失
- **📐 宽度切换** — 375 / 390 / 414 px 三种手机宽度对比
- **📊 自动统计** — 汉字数 / 阅读时间 / 段落数
- **💾 自动保存** — 刷新页面不丢失内容
- **📂 拖拽加载** — 拖拽 .html 文件到页面即可加载
- **🔄 迭代编辑** — 排版后不满意，直接修改，无需重新生成

## 安装

### 方式一：Reasonix（原生支持）

```bash
# 通过 Git 安装
git clone https://github.com/your-username/wemd-ai-skill.git ~/.reasonix/skills/WeMD-AI-skill

# 或一键安装（macOS / Linux）
bash -c "$(curl -fsSL https://raw.githubusercontent.com/your-username/wemd-ai-skill/main/install.sh)"

# 重启 Reasonix 后即可使用
```

使用：

```
/wemd 帮我排版：今天写了一篇关于……的文章……
或直接说：帮我排版，这是内容……
```

### 方式二：Claude Code / Cursor / 其他 AI 编码助手

将 `WeMD-AI-skill/` 目录放入项目根目录，然后在 `.claude.md` 或 `.cursorrules` 中添加：

```
本项目包含 WeMD-AI-skill/ 公众号排版工具。
当用户要求"帮我排版"时，请按 WeMD-AI-skill/SKILL.md 的工作流程执行：
1. 读取文章
2. 设计主题（从 WeMD-AI-skill/公众号HTML排版设计规范.md §6.3 选色板）
3. 先读速查卡（附录：AI 速查卡），再按规范生成 HTML
4. 自检后保存到 output/
```

### 方式三：ChatGPT / Kimi / 豆包 / Gemini（通用）

直接复制规范中的核心规则作为 prompt 前缀：

```
请按以下规则排版公众号文章：

规则摘要：
- 容器只允许 <section>，禁止 <div> <h1>-<h6> <a>
- 每个元素：box-sizing:border-box; max-width:100%!important;
- 100% 内联样式，禁止 <style> 标签
- 正文 14px，行高 1.85，字间距 0.3px
- 分隔用 1px 细线，禁用 ··· 三点式
- 颜色只用 #hex / rgb() / rgba()，禁用 hsl()

完整规范见：公众号HTML排版设计规范.md
```

### 方式四：纯手动（不需要任何 AI）

```
1. 用 Markdown 写好文章
2. 打开 WeMD-AI-skill/examples/preview.html（完整编辑器）
3. 在左侧写 HTML（或从 examples 加载示例参考）
4. 右侧手机框实时预览
5. 点击「复制到公众号」→ 公众号后台 Ctrl+V
```

## 使用流程

```
用户说"帮我排版" + 文章
  ↓
Step 1: 读取文章 → 分析调性（类型/情绪/读者）
  ↓
Step 2: 设计主题
  ├─ 用户指定主题 → 直接使用
  ├─ 短文(<500字) → 从 15 套预设选
  └─ 长文/深度  → AI 原创定制
  ↓
Step 3: 生成 HTML
  ├─ 先读速查卡（~80 行）→ 快速定位规则
  └─ 按需翻正文 → 6 组件的布局
  ↓
Step 3.5: 自检
  ├─ 标签检查：禁止 <div> <h1> <a> 等
  ├─ 属性检查：box-sizing + max-width
  ├─ 样式检查：无 position:absolute、无三点式
  └─ 结构检查：6 个组件齐全
  ↓
Step 4: 输出
  ├─ 保存到 output/xxx-预览.html
  ├─ 自动弹出浏览器预览
  └─ 用户一键复制 → 公众号 Ctrl+V
```

### 迭代修改

排版后想微调？直接告诉 AI：

> "标题颜色改深一点"
> "卡片间距太大了"
> "把这个金句换成引用样式"

AI 直接修改输出文件，不重新生成全部内容。

## 为什么做这个

公众号的排版编辑器长期被 135 编辑器、秀米等工具垄断。它们的核心能力是「已知的排版模式 + 手动拖拽」。WeMD 的思路不同：

> **把排版规则写成 AI 能读懂的知识库，让 AI 自动完成排版工作。**

这份 `公众号HTML排版设计规范.md` 基于对大量真实公众号文章源码的逆向分析，把微信公众号渲染引擎的隐式约束——哪些标签可用、哪些 CSS 属性生效、哪些布局模式能稳定工作——全部被写成了可执行的规则集。

## 技术细节

- **零依赖** — 纯 HTML / CSS / JavaScript，不需要任何 npm 包或后端
- **文件协议兼容** — 所有页面均在 `file://` 下工作，无需启动 HTTP 服务器
- **跨页面数据传递** — 使用 `window.name` 机制（IE6+ 支持，`file://` 下可靠）
- **复制机制** — `execCommand('copy')` 富文本复制，降级方案覆盖所有浏览器
- **字体** — SF Mono / JetBrains Mono / Cascadia Code / PingFang SC 自动适配
